# Driver self-test map, read by tests/selftest_tiers.py for the quick tier.
#
# A line `<case> <path>` says that case exercises that file. A changed code file
# that no line names runs the full driver set, so a missing line costs time, not
# coverage. tests/test_selftest_tiers.py fails when a case has no line here, when
# a line names a case that does not exist, or when a named path does not exist.
#
# `@smoke <case>` runs with every quick run. `@shared <path>` means a change to
# that file runs the full driver set, because every case uses it.

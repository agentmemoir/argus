`show` takes two filters, so a reader can ask for one reservation or one machine instead of the whole board. `--reservation-id` narrows the phase records to that reservation, and repeats for more than one; `--machine-id` narrows the phase records and the live publication lock to one machine, and drops the `publication` key when the lock belongs to another machine, so a lock this machine does not hold is not reported as its own. An id the board does not hold is absent from the answer rather than an error, spacing around a value is ignored, and an empty identifier is refused before the board is read.

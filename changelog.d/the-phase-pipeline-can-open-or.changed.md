The phase pipeline can open or reuse its draft pull request and read its check state again, through two gitsync modes. `open-pr` creates a draft for the phase's branch, reuses the one already open for it, and answers `state: blocked` naming the pull request when the newest one for that branch is merged or closed; a pull request list that cannot be read stops the mode rather than reading as none, so a network blip cannot open a second draft. `peek-ci`, removed with no shim in #156, returns as one non-waiting read of the branch's checks: `ok` is true only when gh reported at least one row and every row's bucket is `pass`, because a skipped, neutral, or cancelled check leaves gh's exit code 0 and an empty list is not a pass, and the summary says what ran, what did not, and what is unknown. The pipeline's post-step helper still records this result and exits 0, so a blocked `open-pr` is a note in the record and never a failed step. ([#161](https://github.com/agentmemoir/argus/pull/161))

Two driver configs on one checkout are refused. A phase holds an exclusive lock on the checkout's Git common directory for its whole run. A second config's tick refuses before any branch cut or leftover commit, and `--check` reports the holder. The refusal names the holding config's file name and says to give each driver its own checkout. The OS releases the lock when the phase exits.

A resumed member of a reservation group stays on the group's one branch. The resume path has no selection to read the group from, so it reads the declared group from the member's own phase document before the branch step. Without it the branch step named a branch from the member alone, so the member's receipt was published on a branch the group's joins do not know and a second branch carrying the group's commits was left on the remote. A declaration that cannot be read refuses the resume instead of reading it as "runs alone", the refusal repeats the phases reader's words so it names the document to fix, and it names the way out of the refusal.

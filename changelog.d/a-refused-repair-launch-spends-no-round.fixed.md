A repair launch that runs no agent no longer uses a repair round. This includes a glide run that exits with a non-zero code before it writes its run marker. The session records the refusal in the run folder, and the next tick takes the round back and counts the refusal. A launch that keeps refusing ends in one Needs You after the round budget, and that message gives the rounds that ran, the launches refused, and the last reason. ([#341](https://github.com/agentmemoir/argus/issues/341), [#340](https://github.com/agentmemoir/argus/issues/340))

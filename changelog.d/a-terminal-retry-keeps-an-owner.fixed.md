A terminal retry keeps an owner-edited `harnesses.json`: the `--fresh` restart archives the run directory, glide restores the edited map into the new one and fills only the missing fields (glide #66), and the driver logs the detected owner edit before the restart, naming the file and the run. The estimate reader keys the developer factor on the saved `steps.developer.harness` alone, so a harness-only edit changes the factor key, and an unreadable map is a skipped update, never a stop. Argus never chooses a harness. ([#159](https://github.com/agentmemoir/argus/pull/159))

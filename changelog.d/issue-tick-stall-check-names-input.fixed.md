An issue tick and `argus abandon` no longer raise a `ValueError` traceback for a missing `issue_file` input. The issue stall check reads the issue task file from the issue task folder; with no task file it logs one line naming the input and skips the check. `argus abandon` on an issue with no task file refuses with one line naming the input and changes nothing.

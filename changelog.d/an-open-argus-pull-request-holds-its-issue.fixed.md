An issue with an open Argus pull request, draft or ready, is no longer selected. Argus finds its own pull request by the `issue/<number>-<slug>` branch in this repository, and a pull request list it cannot read selects no issue. A pull request that is ready for review gets no repair round and no check reads. Before, an issue whose claim had expired was picked again, and a fresh run pushed commits onto a pull request already marked ready. ([#306](https://github.com/agentmemoir/argus/issues/306))

A closed Argus pull request no longer blocks a fresh start. When a person removes the claim label, Argus starts the issue again on a new branch with a numeric suffix, such as issue/<number>-<slug>-2, so the new branch never reuses the closed pull request's branch. Before, the issue stayed blocked after its label was removed. ([#306](https://github.com/agentmemoir/argus/issues/306))

The readiness report's two self-tests run git with a fixed configuration (`GIT_CONFIG_GLOBAL` at `/dev/null` and `GIT_CONFIG_NOSYSTEM=1`), so a host's global `core.hooksPath`, signing key, template, or alias no longer reaches their fixture repositories. A machine-wide hook started its hooks inside every fixture git call, which made `make example-check` and `make install-check` several times slower, and a hook that fails made both self-tests fail for a reason that was not in Argus. A repository-local `core.hooksPath` still wins, which is what the rejected-push check installs, and a real run's git calls keep the machine's configuration.
